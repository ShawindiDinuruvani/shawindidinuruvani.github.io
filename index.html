PROJECT 02
DevOps Engine Nginx · Spring Boot · Bash

Blue-Green Zero-Downtime Deployment Engine

Automated zero-downtime release engine for Spring Boot services using dual-port rotation, automated health checks, and instant Nginx hot reloading.

SYSTEM ARCHITECTURE Dual-Port Blue/Green Traffic Shift
Trigger Telegram /deploy
→
Deploy Script detect active port
→
Standby Port spawn new JAR
→
Actuator health == "UP"
→
Nginx Reload hot traffic switch

How Releases & Traffic Shifts Work

  • Dual-Slot Port Alternation: The Spring Boot application is provisioned to alternate between two local ports: Blue (Port 8080) and Green (Port 8081).
  • Remote Deployment Trigger: An automated long-polling script (listen_bot.sh) monitors for /deploy commands sent via the Telegram Bot API.
  • Automated Actuator Health Check: The deploy.sh script launches the new JAR in the background and queries Spring Boot Actuator (/actuator/health). Traffic is never switched until the service returns "UP".
  • Hot Traffic Switch & Rollback Protection: If healthy, Nginx configuration is updated and reloaded on the fly (nginx -s reload) before terminating the previous process. If the health check fails, the new instance is halted immediately, preserving the live active version without disruption.
Implementation Details

I implemented the automated deployment script (deploy.sh), remote bot listener (listen_bot.sh), Nginx reverse proxy configuration, and Spring Boot Actuator integration to create an end-to-end self-verifying release pipeline.
